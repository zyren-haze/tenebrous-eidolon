# 夢囈手帳 · 沉浸式電子手帳本

面向「夢女」的電子手帳：可以自由拼貼圖文、記錄日常碎碎念，也能與「夢角」保持一條實時的生命體徵連線。

## 快速開始

- **直接打開**：雙擊 `梦呓手账本.html` 即可用，無需安裝、無需聯網、無需構建。第一次打開會自帶一本示例本子。
- **帶雲端**：`node server/server.js`，然後瀏覽 http://localhost:5178 ，在右上角「雲端」裡註冊 / 登入。

> 單文件版本把結構數據存在 `localStorage`、圖片存在 `IndexedDB`，完全離線可用；
> 接上 server 後，結構數據進 MongoDB（或 JSON 文件），圖片進 OSS，並自動每日備份。

## 功能

**書架**
- 無限創建本子，自定義名稱、封面（8 種底紋或上傳圖片）、紙張。
- 每本可綁定獨立角色人設；卡片懸停可編輯 / 刪除。

**自由畫布**
- 元素自由拖拽、旋轉、縮放、圖層上下移動；雙擊文字直接書寫。
- 文字：5 種字體（楷 / 宋 / 行書 / 草書 / 黑體）、字號、顏色、字間距、便籤底。
- 圖片：上傳後自動壓縮（最長邊 1400），可切換拍立得 / 膠帶 / 迴紋針 / 圓框 / 無框，支援圖說。
- 樂曲卡片：歌名、歌手、歌詞片段、封面。
- 貼紙：13 枚手繪 SVG（心、星、月、花、蝴蝶、緞帶、鑰匙、羽毛、火焰、眼⋯）。
- 分區模板：自由 / 田字格 / 上一下二 / 左一右二 / 六格 / 斜分；格內仍可自由排版。
- 紙張：橫線 / 方格 / 點陣 / 空白 / 牛皮 / 夜紙，一鍵切換。

**生命體徵**
- 人設：世界觀、性格標籤、補充設定、平靜心率 / 呼吸 / 血壓、作息類型（晨型 / 夜型 / 無規律）。
- 本地生理引擎：按當前時刻、晝夜節律、天氣、性格標籤與隨機擾動推算，2 秒平滑逼近目標值；數值在 8 分鐘桶內穩定，避免亂跳。
- 雲端大模型：人設 + 環境打包給 OpenAI 兼容接口，返回結構化 `{heart_rate, breath_rate, blood_pressure, temperature}`，失敗自動回落本地引擎。
- 心電圖與呼吸波形用 Canvas 繪製，滾動速度、節拍與實時數值同步。
- Web Audio 合成心音與呼吸聲：`lub-dub` 雙擊音 + 帶通噪聲呼吸，按 BPM / 呼吸頻率調度，預設靜音，需點擊開啟。

**保存與備份**
- 編輯即保存（650ms 防抖），頂部顯示「已保存 HH:MM」。
- 匯出備份：JSON 內嵌圖片為 dataURL，可完整搬移。
- 匯入備份：圖片回寫 IndexedDB，跨設備恢復。
- 雲端：登入後自動整包同步（2.5s 防抖），換設備登入即恢復。
- 後端每日 03:01 快照，保留最近 7 天。

## 關於技術選型

藍圖推薦 Vue3 + TS + Fabric.js + GSAP + MongoDB。這裡刻意把前端做成了**單文件、零依賴、零構建**：

- 用戶拿到就能雙擊打開，不需要 `npm install` 與本地環境；斷網也能寫手帳。
- 拖拽 / 旋轉 / 縮放用 Pointer Events + CSS transform 實現，翻頁用 CSS 3D，波形用 Canvas 2D，心音用原生 Web Audio——這幾項的複雜度都不足以需要引入大型庫。
- 數據層做了 `Media` 抽象：本機模式走 IndexedDB，登入後自動改走 `/api/upload`，接口層與 UI 解耦。
- 後端按藍圖保留了 MongoDB / 阿里雲 OSS / 大模型 / 和風天氣 / 定時備份，全部為可選開關，缺失時自動降級。

要遷移到 Vue3 + TS 時，`state` 結構、元素模型、演算函數、API 契約都可以直接搬過去。

## 已知邊界

- 未接後端時沒有真實帳號體系，只有本機數據 + 手動備份。
- 大模型 / 天氣需自備 Key；未配置時生命體徵完全由本地引擎推算。
- 圖片本機存儲受瀏覽器配額限制；圖片很多時建議接 OSS。
- 尚未做多人協作、手帳公開分享、PDF 導出。
