# 夢囈手帳 · 隱私小手機版（v12）

首頁是只給你看的小手機：他的頭像、心·呼吸、紀念日與底部圖標；不再以備忘清單作首頁，也沒有本子、封面、頁碼。

## 快速開始

- **直接打開**：雙擊 `梦呓手账本.html`，零安裝、零聯網、零構建；預設進入隱私小手機首頁。
- **線上版**：`https://zyren-haze.github.io/tenebrous-eidolon/handbook/`
- **可選後端**：`node server/server.js`，打開 `http://localhost:5178`，在「設定 → 帳號與同步」註冊或登入。

> 結構資料存在 `localStorage`（`mengyi.state.v3`），圖片存在 IndexedDB。舊版資料會自動遷移。

## 主要功能

**備忘錄首頁**
- 一則備忘一張卡片，標題取正文第一行；右上「＋」新增，長按或右滑刪除。
- 頂欄「心音」快速開關心跳；「設定」進入設定抽屜。

**編輯頁**
- 文字、圖片、日期、樂曲、貼紙五種元素；拖拽、旋轉、縮放、圖層上下。
- 5 種字體、字號、顏色、字距、便籤底；文字不會被底部工具列擋住。
- 圖片可切拍立得 / 膠帶 / 迴紋針 / 圓框 / 無框，支援圖說與照片上寫字。
- 撤銷 / 重做：Ctrl/Cmd+Z、Shift+Z，以及屬性條按鈕。

**他**
- 全局唯一人設；生命體徵由人設、晝夜、天氣與紀念日推演。
- BPM 每秒微調；心電波形逐搏變異，與心跳聲同步。
- **首頁**：巨大頭像、心跳與呼吸卡、紀念日一行、底部六個圖標（心音 / 呼吸 / 紀念日 / 白噪音 / 散步 / 設定）；點頭像可上傳他的照片。
- **待辦**：收集箱、五個分類、四象限、每日重複與備註。
- **即時 API**：設定最上方「心跳 + 呼吸 · API」，支援 OpenAI / DeepSeek / 通義 / MiniMax 格式，回傳 `heart_rate`、`breath_rate`、`breath_note`、`blood_pressure` 接管推演；失敗回退本地。
- 白噪音與呼吸聲入口在設定頁；首頁底部「呼吸 / 白噪音」圖標可直接開關。

**散步**
- 點底部「散步」打開：開始 / 結束 GPS 實時定位，按 Haversine 累計公里數；本次與累計分開顯示。
- 雷達以你為中心，顯示他的方位與距離；「刷新他的位置」在附近地點裡隨機。
- 「他的位置交給 API」打開後，用同一個 API 回傳 `place`、`distance_m`、`bearing`、`note`，失敗會退回本地隨機。
- 定位只存在本機；室內、隧道、省電模式會影響精度。

**設定**
- 主題、心跳 + 呼吸 API、心跳音量 / 音色 / 後台播放、白噪音、呼吸聲開關與音量、角色人設、紀念日、帳號與同步、備份匯出匯入。
- 待辦資料存在同一個 `state.todos`，備份與雲端同步會一起帶走。

## 登入與同步

GitHub Pages 是純靜態站，沒有後端，所以「登入」不是必須的。

- **換裝置最省事**：設定 → 帳號與同步 → 備份碼 → 生成 → 複製 → 新裝置貼上 → 還原，不用帳號。
- 要自動同步才需要自跑 `server/`，把介面位址填進去，再註冊 / 登入。
- **即時心跳 API**：貼上 OpenAI 兼容位址、模型名與 Key，按「儲存並測試」。MiniMax 可一鍵填入官方直連；沒有 Key 也能用本地推演。401 是 Key 被拒，402 是帳戶額度不足。

## 備註

- 音頻需一次點擊才會發聲（瀏覽器手勢限制）；進入後第一次觸碰頁面會自動接上。
- iPhone 側邊靜音鍵會靜音 Web Audio；心跳聽不到先檢查靜音鍵與媒體音量。
- 手機瀏覽器切後台不一定允許持續播放；省電模式、系統媒體通道與瀏覽器策略都可能中斷，這是平台限制。
- 本版已移除聲音克隆 / 哼唱入口；呼吸聲是獨立合成音軌，與心跳分開開關。
- 匯出備份為 JSON，圖片以 dataURL 內嵌，可完整還原到另一台裝置。
- 雲端為可選項：本地模式不會上傳任何內容。
