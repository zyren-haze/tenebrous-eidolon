# 夢囈手帳 · 沉浸式電子手帳本（v3 淺色版）

面向「夢女」的電子手帳：奶油紙、粉彩條紋封面，能自由拼貼圖文、記錄日子，也留一頁給「他」——
由人設、時間與天氣共同推演生命體徵，心跳聲隨時能聽見。

## 快速開始

- **直接打開**：雙擊 `梦呓手账本.html`，無需安裝、無需聯網、無需構建。
- **可選雲端**：`node server/server.js`，打開 http://localhost:5178 ，在「設定 → 雲端同步」註冊 / 登入。

> 單文件版把結構數據存在 `localStorage`（`mengyi.state.v3`），圖片存在 IndexedDB，完全離線可用。
> 舊版 `mengyi.state.v2` 會自動遷移：每個本子各自的人設收成唯一一份全局人設，舊的開關音效轉為新音效設定。

## 這一版改了什麼

| 項目 | v2 | v3 |
| --- | --- | --- |
| 視覺 | 深色午夜書房 | 奶油紙 + pastel 條紋封面，預設淺色 |
| 主題 | 固定深色 | 跟隨 / 日間 / 夜間；「跟隨」只認系統深淺色 |
| 角色 | 每個本子一套人設 | **全局唯一人設**，本子只是月份本子 |
| 他的頁面 | 無 | 獨立「他」頁：大號 BPM、心電波形、心音開關、紀念日 |
| 音效 | 心跳 + 呼吸 | **只留心跳**，三檔音色，可自訂音檔 |
| 設定 | 不明顯 | 頂欄粉色「設定」按鈕，抽屜式面板 |
| 日期 | 無 | 頁面日期、相簿式紀念日（在一起 / 每年 / 倒數） |
| 天氣 | 手動選擇 | 依月份、季節與當日種子自動推演，不可手動改 |

## 功能

**書架**
- 一個角色、多個月度本子；可改名稱、封面（7 種底紋或上傳圖片）、紙張。
- 紀念日橫幅：在一起第幾天、生日、倒數日，一鍵新增。

**書內**
- 元素自由拖拽、旋轉、縮放、圖層上下移動；雙擊文字直接書寫，新增文字自動進入輸入。
- 文字：5 種字體、字號、顏色、字間距、便籤底。
- 圖片：上傳自動壓縮，可切換拍立得 / 膠帶 / 迴紋針 / 圓框 / 無框，支援圖說。
- 樂曲卡片、13 枚手繪貼紙、6 種分區模板、6 種紙張。

**他**
- 六段人設：基礎身份 / 性格情緒 / 生理數值 / 情境映射 / 專屬音頻 / 備註。
- 生命體徵由 `人設基準 + 晝夜正弦 + 天氣 + 性格關鍵詞 + 體質 + 紀念日` 推演，夾在心率上下限內。
- BPM 每秒微調（心率變異 + 寫字互動 +5～6），心電波形與心跳聲同步變速。
- **即時 API**：設定 → 即時心跳 · API，先點 OpenAI / DeepSeek / 通義 一鍵填接口，再貼 Key、開啟即可；回傳 `{heart_rate, breath_rate, blood_pressure}` 接管推演，失敗自動回退本地引擎。
- 心跳聲可從頂欄、他頁、書內面板三處開關；預設開啟，第一次觸碰頁面後發聲。

**設定抽屜**
- 主題、心跳聲開關 / 音量 / 音色、角色人設、紀念日、雲端同步、匯出 / 匯入備份。

## 檔案

```
梦呓手账本.html      單文件應用（HTML + CSS + JS，零依賴）
server/              可選 Node 後端（Express + MongoDB/JSON，預設 5178）
server/.env.example  環境變量示例
```

## 關於登入

GitHub Pages 是純靜態站，沒有後端，所以「登入」不是必須的。入口：書架右上角「設定 · 登入」或頂欄「設定」。
- **換裝置最省事**：設定 → 登入／雲端同步 → 備份碼 → 生成 → 複製 → 新裝置貼上 → 還原，不用帳號。
- 要自動同步才需要自跑 `server/`（Node + MongoDB/JSON），把介面位址填進去。

## 備註

- 音頻需一次點擊才會發聲（瀏覽器手勢限制）；心音預設開啟，進頁後第一次觸碰會自動接上。音量可在設定裡拉到 100。
- 紙面可左右滑動翻頁（頁碼下方有提示，翻一次後自動消失）；長頁面上下滑動。
- 文字選中後底部出現字體 / 字號 / 顏色 / 完成；調整時紙面自動上移，不会被工具列遮住。
- 撤銷 / 重做：支援 Ctrl/Cmd+Z、Shift+Z，以及屬性條上的按鈕；改字、拖動、改字體都能退回。
- 心跳聲改為內嵌「撲通」採樣，預設音量 95，可拉到 100。
- iPhone 側邊靜音鍵會靜音 Web Audio 合成音，心跳聲聽不到時先檢查靜音鍵。
- 匯出備份為 JSON（圖片以 dataURL 內嵌），可完整還原到另一台裝置。
- 雲端為可選項：本地模式不會上傳任何內容。
