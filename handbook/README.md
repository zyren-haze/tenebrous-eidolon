# 夢囈手帳 · 備忘錄版（v7）

一個人的備忘錄式電子手帳。首頁只列一則一則備忘，點進去就是整屏便籤；跟隨系統深淺色，沒有本子、封面、頁碼、縮圖欄。

## 快速開始

- **直接打開**：雙擊 `梦呓手账本.html`，零安裝、零聯網、零構建。
- **線上版**：`https://zyren-haze.github.io/tenebrous-eidolon/handbook/`
- **可選後端**：`node server/server.js`，打開 `http://localhost:5178`，在「設定 → 帳號與同步」註冊或登入。

> 結構資料存在 `localStorage`（`mengyi.state.v3`），圖片存在 IndexedDB。舊版資料會自動遷移。

## v7 加了什麼

| 項目 | 行為 |
| --- | --- |
| 保存 / 編輯 | 編輯頁頂欄一鍵「保存」，版面鎖住；再按「編輯」解鎖。鎖住後元素不可拖、底部工具列收起，但仍然自動保存。 |
| 照片上寫字 | 選中照片後按「照片上寫字」，文字直接疊在照片中央；也可先點「文字」再點畫布任意位置。文字可拖、可轉、可縮放、可改字體顏色。 |
| 貼圖 | 由 12 枚擴充到 28 枚，5 欄選取。 |
| 他的哼唱 | 隨機五聲音階小調，低沉 / 溫柔 / 清亮三種聲線，可試聽、可調音量。純網頁合成，不是真正的聲音克隆。 |
| 白噪音 | 雨、海、火、純白四種，可調音量。 |
| 心跳 | 預設 140%，滑桿最高 160%；採樣改成更低的「撲通」，去掉高頻電波感。 |
| 後台心跳 | 切到後台改用循環音訊繼續播；回到前台恢復即時心跳。手機省電模式或系統媒體通道可能把它停掉。 |

## 主要功能

**備忘錄首頁**
- 一則備忘一張卡片，標題取正文第一行；右上「＋」新增，長按或右滑刪除。
- 頂欄「心音」快速開關心跳；「設定」進入設定抽屜。

**編輯頁**
- 文字、圖片、日期、樂曲、貼紙五種元素；拖拽、旋轉、縮放、圖層上下。
- 5 種字體、字號、顏色、字距、便籤底；文字不會被底部工具列擋住。
- 圖片可切拍立得 / 膠帶 / 迴紋針 / 圓框 / 無框，支援圖說與照片上寫字。
- 撤銷 / 重做：Ctrl/Cmd+Z、Shift+Z，以及屬性條按鈕。

**他**
- 全局唯一人設；生命體徵由人設、晝夜、天氣與紀念日推演。
- BPM 每秒微調，心電波形與心跳聲同步。
- **即時 API**：設定 → 即時心跳 · API，支援 OpenAI / DeepSeek / 通義格式，回傳 `heart_rate`、`breath_rate`、`blood_pressure` 接管推演；失敗回退本地。
- 哼唱與白噪音入口在設定頁；他頁也有哼唱快捷開關。

**設定**
- 主題、心跳音量 / 音色 / 後台播放、哼唱、白噪音、人設、紀念日、API、帳號與同步、備份匯出匯入。

## 登入與同步

GitHub Pages 是純靜態站，沒有後端，所以「登入」不是必須的。

- **換裝置最省事**：設定 → 帳號與同步 → 備份碼 → 生成 → 複製 → 新裝置貼上 → 還原，不用帳號。
- 要自動同步才需要自跑 `server/`，把介面位址填進去，再註冊 / 登入。
- **即時心跳 API**：貼上 `https://api.openai.com/v1` 這類位址、模型名與 Key，按「儲存並測試」。沒有 Key 也能用本地推演。

## 備註

- 音頻需一次點擊才會發聲（瀏覽器手勢限制）；進入後第一次觸碰頁面會自動接上。
- iPhone 側邊靜音鍵會靜音 Web Audio；心跳聽不到先檢查靜音鍵與媒體音量。
- 手機瀏覽器切後台不一定允許持續播放；省電模式、系統媒體通道與瀏覽器策略都可能中斷，這是平台限制。
- 真正的聲音克隆需要後端 TTS / voice cloning 服務與參考音檔，純靜態網頁做不到；本版提供的是可調聲線的合成哼唱。
- 匯出備份為 JSON，圖片以 dataURL 內嵌，可完整還原到另一台裝置。
- 雲端為可選項：本地模式不會上傳任何內容。
